# Українська локалізація phpBB

Повний переклад мовного пакету [phpBB](https://www.phpbb.com/) версії **3.3.17** на українську мову.

## Що входить до пакету

- **Основні мовні файли** (`language/uk/*.php`) — усі рядки інтерфейсу форуму: реєстрація, публікації, особисті повідомлення, пошук, панель модератора, встановлення/оновлення (CLI, install/update wizard) тощо.
- **Довідка** (`language/uk/help/`) — довідник BBCode та ЧаП (FAQ).
- **Панель адміністрування** (`language/uk/acp/`) — усі розділи ПА: загальні налаштування, права доступу, керування форумами, користувачами, групами, розширеннями, журнали тощо.
- **Email-шаблони** (`language/uk/email/`, `language/uk/email/short/`) — усі листи, які надсилає форум (активація, сповіщення, скарги, попередження тощо).
- **Мовний файл розширення VigLink** (`ext/phpbb/viglink/language/uk/`).
- Технічні файли (`iso.txt`, `LICENSE`, `index.htm`) та стильові ресурси (`styles/prosilver/theme/uk/`).

## Встановлення

1. Розпакуйте архів `ukrainian_3_3_17.zip`.
2. Завантажте вміст теки `language/uk/`, `ext/phpbb/viglink/language/uk/` та `styles/prosilver/theme/uk/` у відповідні теки вашого встановлення phpBB (зберігаючи структуру).
3. Перейдіть у ПА → **Загальні** → **Мова** → **Мовні пакети** та встановіть мовний пакет «Українська».
4. За потреби зробіть українську мову мовою форуму за замовчуванням у **Загальні налаштування** → **Налаштування форуму**.

## Правило множини

Для української мови встановлено `PLURAL_RULE = 7` (форми: один / кілька / багато), що коректно відображає кількісні форми на кшталт «1 тема» / «2 теми» / «5 тем».
